Is this clip game-ready?

AnimSmith lints skeletal animation clips for the problems that only show up after import: popped loops, sliding feet, drifting root motion, T-posed limbs. Point it at a glTF or FBX export and get frame- and bone-level evidence in seconds: on the command line while the DCC is still open, or in CI and as a Rust library once the contract is declared.

$ cargo install animsmith
$ animsmith lint walk.glb
